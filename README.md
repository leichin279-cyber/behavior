# 행동기록 · 탭 두 번

장애학생의 행동을 **탭 두 번**으로 기록하는 특수교육용 도구입니다.
관찰 중에는 아무 판단도 요구하지 않고, 무거운 설정은 전부 사전 단계로 옮겼습니다.

- 설치 없이 브라우저에서 동작 · 빌드 도구 없음 · 외부 라이브러리 없음
- 스마트폰 / 태블릿 / PC 화면에 자동으로 맞춰짐
- 오프라인 동작 (교실 와이파이가 끊겨도 계속 기록)
- 서버 전송 없음 — 데이터는 기기 안에만 저장

---

## 바로 써보기

1. 이 저장소를 내려받아 `index.html`을 브라우저로 엽니다.
2. 또는 GitHub Pages로 배포합니다 — Settings → Pages → Source를 `main` 브랜치 루트로 지정.
   배포 후 주소를 휴대폰에서 열고 **홈 화면에 추가**하면 앱처럼 전체화면으로 실행됩니다.

로컬에서 서비스워커까지 확인하려면 정적 서버가 필요합니다.

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

## 사용 흐름

### 기록 (매일)

```
학생 선택 → 교시·장소·활동 지정 → 세션 시작
   → [탭 1] 행동 영역   → [탭 2] 세부행동   → 저장
```

두 번째 탭 이후는 **행동에 미리 배정된 측정방식**에 따라 앱이 알아서 갈라집니다.

| 측정방식 | 두 번째 탭에서 일어나는 일 |
|---|---|
| 빈도 | 즉시 저장. 타일에 누적 횟수 표시 |
| 지속시간 | 타이머 시작. 같은 타일을 다시 누르면 종료 (동시 2건까지) |
| 지연시간 | 상단 `지시 제시`를 누른 시각부터 자동 계산. 설정 시간 초과 시 무반응 처리 |
| 강도 | 기본값 2로 자동 저장. 급하지 않을 때만 스낵바에서 조정 |

저장 직후 하단에 실행취소 · 선행사건 · 후속결과가 뜹니다. 누르지 않으면 그냥 사라집니다.
세부행동을 **길게 누르면** 조작적 정의가 열립니다.

### 간격기록 (별도 모드)

고빈도 상동행동처럼 세는 것이 불가능할 때 사용합니다. 세션 시작 시 `간격기록`을 고르고
행동 1~3개, 방식(부분간격 / 전체간격 / 순간표집), 간격 길이, 총 관찰시간을 정하면
간격마다 진동이 울리고 발생 비율이 산출됩니다.

> 부분간격은 과대추정, 전체간격과 순간표집은 과소추정하는 성질이 있습니다.
> 비교는 반드시 같은 방식·같은 간격 길이끼리만 하세요.

### 설정

영역, 세부행동, 선행사건, 후속결과를 모두 직접 수정·추가할 수 있습니다.
삭제 대신 **보관**되므로 지난 기록이 깨지지 않습니다.
행동 세트는 JSON으로 내보내 다른 학생에게 복사하거나 동료와 나눌 수 있습니다.

### 저장 위치

`window.storage`가 있으면 그것을, 없으면 `localStorage`를 씁니다.
어느 쪽이든 **기기 안에만** 저장되고 서버로 나가지 않습니다.
브라우저 데이터를 지우면 함께 사라지므로 설정 → 데이터에서 주기적으로 백업하세요.

개인정보 보호를 위해 학생은 실명 대신 이니셜이나 코드명으로 등록하는 것을 권합니다.

## 저장과 개인정보

기록은 **접속한 기기의 브라우저 안에만** 저장됩니다. Vercel이나 GitHub 서버로 전송되지 않습니다.

- 브라우저를 닫거나 기기를 꺼도 기록은 남습니다.
- 같은 주소를 다른 사람이 열어도 **빈 앱**이 보입니다. 서로의 기록은 보이지 않습니다.
- 다만 **같은 기기의 같은 브라우저**를 쓰는 사람에게는 보입니다. 공용 PC는 피하세요.
- **기기끼리 동기화되지 않습니다.** 휴대폰과 PC의 기록은 별개입니다. 옮기려면 전체 백업을 내보내 가져오기 하세요.

### 데이터가 사라질 수 있는 경우

| 상황 | 대책 |
|---|---|
| 브라우저 데이터 삭제 | 주기적으로 전체 백업 내보내기 |
| 시크릿·프라이빗 모드 | 일반 창에서 사용 |
| iOS 사파리 7일 미접속 | **홈 화면에 추가**하면 제외됨 |
| 기기 저장공간 부족 | 첫 실행 시 영구 보존을 자동 요청 |

앱은 실행 시 `navigator.storage.persist()`로 영구 보존을 요청하고, 설정 → 데이터에서 승인 여부를 확인할 수 있습니다.
기록이 20건을 넘고 마지막 백업이 7일 이상 지나면 홈 화면에 백업 알림이 뜹니다.

학생은 실명 대신 이니셜이나 코드명으로 등록하세요. 기기 분실 시 차이가 큽니다.

### Vercel 배포

저장소를 Vercel에 연결하면 별도 설정 없이 정적 사이트로 배포됩니다.
주소를 아는 사람은 누구나 앱을 열 수 있지만 기록은 보이지 않습니다.
주소 자체를 가리려면 Vercel 프로젝트 설정의 Deployment Protection을 켜세요.

## 만들 때 지킨 원칙

1. **관찰 중에는 판단을 요구하지 않는다.** 측정방식은 설정 단계에서 이미 정해져 있습니다.
2. **오터치는 반드시 일어난다.** 실행취소가 어려우면 교사는 기록 자체를 포기합니다.
3. **삭제하지 않는다.** 보관으로 숨기고 과거 기록은 지킵니다.
4. **조작적 정의를 도구 안에 둔다.** 정의 없는 데이터는 중재 효과 판단에 쓸 수 없습니다.
5. **대체행동을 같은 무게로 센다.** IEP 성과는 문제행동 감소가 아니라 대체행동 증가로 보고됩니다.
